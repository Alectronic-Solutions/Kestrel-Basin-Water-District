# Kestrel Basin Water District demonstration site

This project follows the `gov-site` skill baseline. Kestrel Basin, Adelmar County,
and the surrounding communities are fictional. Keep the permanent demonstration banner
and `noindex, nofollow` metadata on every route. Build for WCAG 2.1 AA and Section 508,
use semantic landmarks, and retain the static-export configuration.

The experience should feel like an information-rich California special-district website,
with prominent meeting, transparency, conservation, and customer-service paths. The
bill estimator is educational only and must never be framed as an official bill.
